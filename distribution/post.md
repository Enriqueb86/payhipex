# Distribution post

Offsite Ads can turn a sale that looks healthy into a much thinner order. To estimate the effect, start with the order total: item price multiplied by quantity, plus shipping charged. Subtract any refund, then multiply the remaining amount by your current Offsite Ads rate—usually 15%, or 12% for shops that have crossed Etsy’s threshold. That ad fee is only one layer: listing, transaction, payment processing, and any Etsy Ads spend still need to be deducted.

For example, a $70 order attributed to an Offsite Ad can carry a $10.50 Offsite Ads fee at 15% before the other Etsy fees are counted. Keeping the calculation at order level makes it easier to see which sales actually produced a useful margin.
